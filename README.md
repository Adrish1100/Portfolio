## 📖 Overview

**Adrish Portfolio** is a responsive personal portfolio website designed to showcase skills, projects, and contact information in a clean dark-themed interface.

It is intended for students, developers, and anyone who wants a simple portfolio website that is easy to customize and deploy.

# ⚙ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Adrish-Portfolio.git
```

Go into the project folder:

```bash
cd Adrish-Portfolio
```

No dependencies are required.

---

# ▶️ Usage

Simply open the project:

```bash
start index.html
```

or double-click **index.html**.

You can also serve it locally:

```bash
python -m http.server 8000
```

Then visit:

```
http://localhost:8000
```
